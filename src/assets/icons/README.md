# NovaBank favicons (offline)

Self-hosted brand icons for browser tabs, bookmarks, and PWA-style shortcuts.
No CDN — files live under this folder and are referenced from `src/index.html`.

| File | Use |
| --- | --- |
| `favicon.svg` | Modern browsers (crisp at any DPI) |
| `favicon.ico` | Legacy / shortcut icon (16 / 32 / 48) |
| `favicon-16.png` / `favicon-32.png` | Explicit PNG sizes |
| `apple-touch-icon.png` | iOS home screen (180×180) |
| `icon-192.png` / `icon-512.png` | Larger app / notification icons |

Design matches the NovaBank nav mark: teal → sky gradient tile with an **N** / **NB** monogram.
